Задание №1
Необходимо:
• объяснить, почему интерфейс не обновился;
	
	Child не изменился потому что ссылка на объект осталась прежней несмотря на изменение свойства объекта. При стратегии OnPush изменение свойства объекта не приводит к проверке ChildComponent, если ссылка на объект, переданный через @Input, не изменилась.

• исправить проблему минимум одним способом.

	правильный подход: не изменять существующий объект, а создать новый объект.
	this.user = {
		...this.user,
		name: 'Eugene'
	};

Задание №3
Цель: Понять назначение методов ChangeDetectorRef, различия между ними и случаи их практического применения
Задача: Продублируйте компонент с задания №2, только переключите стратегию компонента на  ChangeDetectionStrategy.OnPush 

========================================================
Часть 1. markForCheck()
Реализуйте сценарий, в котором изменение count не приводит к обновлению интерфейса автоматически. После изменения значения вызовите markForCheck();

Ответьте:
1. Что произошло после вызова markForCheck()?
2. Обновился ли интерфейс сразу?
3. Когда фактически произошел Change Detection?
4. Почему без markForCheck() интерфейс не обновлялся?

1. Компонент был помечен Angular для последующей проверки CD.
2. Нет. markForCheck() сам по себе не запускает CD немедленно.
3. После завершения setTimeout, когда Angular запустил очередной цикл CD.
4. Без markForCheck() интерфейс не обновлялся, потому что при стратегии OnPush компонент не был помечен для проверки CD. 
   Изменение обычного поля count внутри setTimeout() само по себе не делает OnPush-компонент проверяемым.

Часть 2. detectChanges(). Реализуйте аналогичный сценарий, но вместо markForCheck() используйте detectChanges(); Ответьте:

2. Выполняется ли CD немедленно? 
3. Какие компоненты были проверены? 
4. В каких случаях использование detectChanges() предпочтительнее? 


1. при detectChanges() происходит проверка немедленно, то есть detectChanges() не ждёт следующего глобального цикла Change Detection.
2. Да. Это главное свойство detectChanges().
3. detectChanges() проверяет компонент, на ChangeDetectorRef которого он вызван, и его дочерние компоненты.
4. Когда нам нужна немедленная локальная проверка.
